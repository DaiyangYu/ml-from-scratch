# K-means

建议用时：15 分钟

## 要实现什么

在 `kmeans.py` 中只用 numpy 实现 K-means 聚类函数 `kmeans`（Lloyd 算法）。初始中心由调用者传入，所以结果是确定的。

从初始中心出发，重复以下两步，每做完两步算一轮：

1. 分配：把每个样本分给欧氏距离最近的中心；距离相同时取编号最小的中心。
2. 更新：把每个中心改为分给它的全部样本的均值；没有分到任何样本的中心保持不变。

做满 `max_iters` 轮后停止。如果某一轮更新之后所有中心都没有变化，可以提前停止（结果相同）。

返回最终的中心，以及每个样本在**最终中心**下的分配结果。

## 接口

`kmeans(X, init_centers, max_iters=100)`

| 参数 | 说明 |
| --- | --- |
| `X` | 形状 `[n, d]` 的数组，可能是整数类型 |
| `init_centers` | 形状 `[k, d]` 的数组，初始中心 |
| `max_iters` | 最多做多少轮；为 0 时中心就是初始中心 |

返回 `(centers, labels)`：

- `centers`：形状 `[k, d]` 的浮点数组
- `labels`：形状 `[n]` 的整数数组，取值 0 到 k−1

## 必须正确处理的情况

- 出现空簇（某个中心没有分到样本）时，结果中不能出现 `nan`。
- 不能改动调用者传入的 `X` 和 `init_centers`。

## 不要求

- 随机初始化、k-means++
- 多次重启取最优
- 小批量版本

## 检验方式

- 与逐样本、逐中心按定义写的循环实现对比。
- 手算的小例子。
- 收敛后每个中心等于簇内均值；轮数增加时簇内平方误差之和不会增大。
- 与参考实现对比。
