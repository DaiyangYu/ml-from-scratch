# MF：矩阵分解

建议用时：5 分钟

## 要实现什么

在 `mf.py` 中实现 `MF(nn.Module)`。每个用户和每个物品各有一个 `dim` 维向量，用户对物品的预测分是这两个向量的点积：

```
ŷ(u, i) = <p_u, q_i>
```

## 接口

构造：`MF(num_users, num_items, dim=32)`

参数名（测试按名字读写权重，必须一致）：

| 属性 | 定义 |
| --- | --- |
| `user_emb` | `nn.Embedding(num_users, dim)`，用户向量 |
| `item_emb` | `nn.Embedding(num_items, dim)`，物品向量 |

`forward(user_ids, item_ids)`：两个输入都是形状 `[B]` 的整数张量，返回形状 `[B]` 的张量，第 `b` 个元素是第 `b` 个用户对第 `b` 个物品的预测分。

## 不要求

- 特定的初始化方式
- 用户偏置、物品偏置、全局偏置
- 损失函数、训练

## 检验方式

- 与手算值、按定义逐样本计算的点积对比。
- 与参考实现在相同权重下对比。
