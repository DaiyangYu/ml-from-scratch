# MicroGrad：标量自动微分

建议用时：30 分钟

## 要实现什么

在 `micrograd.py` 中实现类 `Value`：包装一个标量，记录它由哪些运算得来，并能通过反向传播求出最终结果对计算图中每个节点的导数。

## 接口

| 接口 | 说明 |
| --- | --- |
| `Value(data)` | 用一个 Python 数构造。构造函数可以自行增加带默认值的参数 |
| `.data` | 数值 |
| `.grad` | 导数，初始为 `0.0` |
| `a + b`、`a - b`、`a * b`、`a / b`、`-a` | 两侧都可以是 `Value` 或 Python 数，例如 `2 * a`、`1 - a`、`1 / a` 都要支持 |
| `a ** k` | `k` 是 Python 数（整数或浮点数），不要求 `k` 是 `Value` |
| `.tanh()`、`.relu()` | 返回新的 `Value` |
| `.backward()` | 把自身的 `grad` 置为 1，然后把导数传播到计算图中所有上游节点 |

## 必须正确处理的情况

- 同一个节点在表达式中被使用多次（如 `a + a`、`a * a`），导数要累加。
- 计算图有分叉再汇合的结构时，一个节点必须在所有下游节点的导数都传回之后，才能继续向上游传播。

## 不要求

- 张量、广播、批量运算
- `Neuron`、`Layer`、`MLP` 等神经网络封装
- 重复调用 `backward()` 时的清零逻辑

## 检验方式

`test_micrograd.py` 把 `backward()` 的结果与数值微分（中心差分）的结果对比。
