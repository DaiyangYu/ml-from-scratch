# Recall@K 与 NDCG@K

建议用时：10 分钟

## 要实现什么

在 `topk_metrics.py` 中实现召回和排序阶段最常用的两个 Top-K 指标。两个函数都只处理一个用户，相关性只有“相关”和“不相关”两种。

**`recall_at_k(ranked_items, relevant_items, k)`**

推荐列表的前 `k` 个里命中了多少个相关物品，除以相关物品的总数。

**`ndcg_at_k(ranked_items, relevant_items, k)`**

NDCG@K = DCG@K / IDCG@K。

- DCG@K：推荐列表前 `k` 个位置上的收益之和。第 `i` 个位置（`i` 从 1 数起）上的物品相关时，收益为 `1 / log2(i + 1)`，不相关时收益为 0。
- IDCG@K：理想排序下的 DCG@K，即把相关物品全部排在最前面时能得到的最大值。相关物品不足 `k` 个时，理想排序里也只有这么多个相关物品。

## 接口

| 参数 | 含义 |
| --- | --- |
| `ranked_items` | 物品 id 的列表，已按模型分数从高到低排好，没有重复；长度可能小于 `k` |
| `relevant_items` | 该用户的相关物品 id，集合或列表，非空，没有重复 |
| `k` | 正整数 |

两个函数都返回 0 到 1 之间的浮点数。

## 必须正确处理的情况

- `k` 大于推荐列表的长度。
- 相关物品的个数大于 `k`，或者小于 `k`。
- 前 `k` 个里一个都没有命中。

## 不要求

- 多级相关性（相关程度有多个等级）
- 对多个用户取平均
- 从分数生成排序

## 检验方式

- 与手算值、逐个位置按定义计算的结果对比。
- 与参考实现对比。
