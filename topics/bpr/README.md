# BPR 损失

建议用时：5 分钟

## 要实现什么

在 `bpr.py` 中实现函数 `bpr_loss`：贝叶斯个性化排序（Bayesian Personalized Ranking）的成对损失。

每个样本是一个三元组（用户，正样本物品，负样本物品），正样本是用户交互过的物品，负样本是用户没有交互过的物品。损失希望模型给正样本的打分高于给负样本的打分：正样本分数比负样本分数高得越多，损失越小。最终损失是各样本损失对 batch 的平均。

## 接口

`bpr_loss(model, users, pos_items, neg_items)`

| 参数 | 含义 |
| --- | --- |
| `model` | 任意可调用对象，`model(users, items)` 返回形状 `[B]` 的打分 |
| `users` | `[B]`，用户 id |
| `pos_items` | `[B]`，正样本物品 id |
| `neg_items` | `[B]`，负样本物品 id |

返回标量张量（0 维），梯度能够传回 `model` 的参数。

## 必须正确处理的情况

- 正负样本的分数差很大（例如相差 200）时，损失仍是有限值，不能出现 `inf` 或 `nan`。

## 不要求

- 负样本的采样
- 正则项
- 打分模型本身（测试会传入现成的打分函数）

## 检验方式

- 用一张固定的打分表作为 `model`，与手算值、按定义逐样本计算的结果对比。
- 检查方向：提高正样本分数应使损失下降，提高负样本分数应使损失上升。
- 与参考实现对比。
