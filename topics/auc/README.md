# AUC 与 GAUC

建议用时：15 分钟

## 要实现什么

在 `auc.py` 中用 numpy 实现两个评估指标。

**`auc(labels, scores)`**

AUC 的定义：随机取一个正样本和一个负样本，正样本的分数高于负样本分数的概率。分数相同的一对正负样本按 0.5 计。

时间复杂度必须是 `O(n log n)`，不能两两比较正负样本对。测试里有一条 20 万样本的用例，限时 10 秒，内存上限 4 GB。

**`gauc(labels, scores, user_ids)`**

GAUC（分组 AUC）：对每个用户的样本单独计算 AUC，再按各用户的样本数加权平均。只有正样本或只有负样本的用户不参与计算，既不计入加权和，也不计入权重之和。

## 接口

| 参数 | 含义 |
| --- | --- |
| `labels` | 长度为 `n` 的一维数组，取值 0 或 1（1 为正样本） |
| `scores` | 长度为 `n` 的一维数组，模型给出的分数，可能有重复值 |
| `user_ids` | 长度为 `n` 的一维整数数组，每个样本所属的用户 |

三个参数既可能是 numpy 数组，也可能是 Python 列表。两个函数都返回一个浮点数。

可以认为：`auc` 的输入里正负样本都存在；`gauc` 的输入里至少有一个用户同时有正负样本。

## 必须正确处理的情况

- 分数相同的样本，无论它们在输入中的先后顺序如何，结果都一样。
- 正负样本数量相差很大。

## 不要求

- ROC 曲线本身（各个阈值下的真正率、假正率）
- 多分类
- `gauc` 的效率

## 检验方式

- 与手算值、按定义两重循环统计正负样本对的结果对比。
- 大规模用例在子进程中运行，检查耗时和内存。
- 与参考实现对比。
