# 逻辑回归

建议用时：15 分钟

## 要实现什么

在 `logistic_regression.py` 中只用 numpy 实现二分类的逻辑回归 `LogisticRegression`，用全量梯度下降训练。梯度要自己推导，不能使用自动求导。

模型：样本 `x` 属于正类的概率是 `sigmoid(w · x + b)`。

训练（`fit`）：

- 权重 `w` 和偏置 `b` 都从 0 开始。每次调用 `fit` 都重新从 0 开始，不接着上一次的结果训练。
- 损失是二元交叉熵对全部样本的平均值，不加正则项。
- 每一步用全部样本算出损失对 `w` 和 `b` 的梯度，然后同时更新：`参数 ← 参数 − lr × 梯度`。
- 一共做 `n_iters` 步。

## 接口

构造：`LogisticRegression(lr=0.1, n_iters=1000)`

属性名（测试会读取，必须一致）：

| 属性 | 含义 |
| --- | --- |
| `w` | 形状 `[d]` 的 numpy 数组，权重 |
| `b` | 标量，偏置 |

方法：

| 方法 | 说明 |
| --- | --- |
| `fit(X, y)` | `X` 是形状 `[n, d]` 的数组，`y` 是形状 `[n]` 的数组，取值 0 或 1（可能是整数类型）；训练后返回 `self` |
| `predict_proba(X)` | 返回形状 `[n]` 的数组，每个样本属于正类的概率 |
| `predict(X)` | 返回形状 `[n]` 的数组，取值 0 或 1；概率不小于 0.5 判为 1 |

## 必须正确处理的情况

- `w · x + b` 的绝对值很大（例如 ±1000）时，`predict_proba` 的结果仍然是 0 到 1 之间的数，不能出现 `nan`。

## 不要求

- 正则项、小批量或随机梯度下降、提前停止
- 多分类
- 特征标准化

## 检验方式

- 用 PyTorch 的自动求导从同样的起点做同样步数的梯度下降，比较最终的 `w` 和 `b`。
- 手算第一步更新后的参数。
- 在线性可分的数据上检查准确率。
- 与参考实现对比。
